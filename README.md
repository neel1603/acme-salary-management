# ACME Salary Management

A web-based salary management and analytics platform for ACME Corp's HR team — replacing spreadsheet-based salary tracking for a 10,000-employee, multi-country organization.

Built as a take-home engineering assessment for Incubyte's Software Craftsperson (Python/React/AI) role.

## Status

Work in progress. See `docs/` for design artifacts as they land, and the commit history for how the solution evolved.

## Stack (planned)

- **Backend**: Python 3.12, FastAPI, SQLAlchemy, SQLite
- **Frontend**: React (Vite), shadcn/ui, Recharts
- **Tests**: pytest, Vitest + React Testing Library
- **Local run**: Docker Compose (one command)
